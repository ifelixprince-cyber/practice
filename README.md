Corrections on Html – Practice
HTML Corrections Breakdown

•	Heading Hierarchy: Change <h3> and <h4> to <h2> elements. Subheadings under the main <h1> should share the same structural level unless nested beneath a parent section.

•	Capitalization: Capitalize proper nouns and section titles ("My Lists", "South Korea", "eFootball", "FIFA", "Call of Duty", "PUBG Mobile", "Grand Theft Auto V").


•	Apostrophe Misuse: Change Todo's to Todos or To-Do List (plural, not possessive).
•	Indentation & Formatting: Remove unnecessary trailing blank lines before closing tags (</ol>, </body>). Use Prettier to format the html code.
